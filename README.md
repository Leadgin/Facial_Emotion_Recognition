This is a group assignment project of Artificial Intelligence (AI).

This project performs Exploratory Data Analysis (EDA) and builds a Convolutional Neural Network (CNN) for Facial Expression Recognition (FER) using the FER2013 dataset.
https://www.kaggle.com/code/drcapa/facial-expression-eda-cnn

The FER2013 dataset contains 48×48 grayscale facial images, each labeled with one of seven emotions:
1. Angry
2. Disgust
3. Fear
4. Happy
5. Sad
6. Surprise
7. Neutral
   
To run the file
1. Download all files from https://drive.google.com/drive/folders/1em6nvT8_jLD011qllh-uhk4YR7bNrRLI?usp=sharing
2. Ensure all files are locate in the same folder.
3. Run 0_mainApp.py
